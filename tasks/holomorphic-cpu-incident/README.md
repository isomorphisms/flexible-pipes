# Holomorphic CPU incident qualification

The hosted workflow runs the independent ai-ci CPU oracle recorded in
[Flexible Pipes issue #69](https://github.com/isomorphisms/flexible-pipes/issues/69).
It checks out the original Holomorphic specimen and the strengthened ai-ci
verifier at their reviewed commits. The pinned ICK action qualifies the
compiler. Checked Ithon runs the existing owner procedures and keeps both
process exits and their stdout and stderr.

The workflow emits a host CPU verdict only after the good control and five
deliberately wrong evaluators have run, the independent receipt has passed,
and the altered-evidence cases have been rejected. The verdict binds the
control revision, both source revisions, compiler identity and evidence
digest. Failure before either owner procedure finishes leaves the original
process evidence available.

This candidate exercises the Flexible Pipes hosted qualification path. The
protected installed service currently recognizes Kitchen and exporter
operations. Admitting this CPU operation there still requires the approved
runtime material, authority and transition integration. Sampling policy,
generated GPU shader execution, and physical-device obligations remain open.
