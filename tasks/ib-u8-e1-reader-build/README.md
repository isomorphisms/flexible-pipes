# IB-U8-E1 reader-build handoff

The pipeline compiles Ike with the pinned ICK action, has Ike invoke AI-CI's
independent source/material preflight, and then composes the literal Kitchen
assignment. It deliberately stops before package work at
`AWAITING_HANDOFF_DELIVERY`: no local response file or GitHub commit is treated
as a visible assignment. The Kitchen contract owns the material bundle and the
future build controls.
