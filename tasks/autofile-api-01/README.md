# STAR-AUTOFILE-API-01 registration

This directory records the authorization and immutable source chain for the
ChatGPT Projects API adapter preflight.

The workflow checks exact source heads through this control path:

1. Flexible Pipes validates the checked-in plan.
2. Grease enters the maintained Kitchen procedure.
3. Source-pinned Ike orders the toolchain, producer and independent checks.
4. Source-qualified ICK compiles the maintained C.
5. Independent ai-ci tests the write boundary and post-write verification.

Related drafts:

- producer: [isomorphisms/autofile-chatgpt-threads#2](https://github.com/isomorphisms/autofile-chatgpt-threads/pull/2)
- independent acceptance: [isomorphisms/ai-ci#281](https://github.com/isomorphisms/ai-ci/pull/281)
- Kitchen/Ike procedure: [isomorphisms/kitchen#62](https://github.com/isomorphisms/kitchen/pull/62)

A passing preflight is source and synthetic-fixture evidence. It does not
authorize or claim browser authentication, a private endpoint call, a live
conversation move, classifier behavior, production-controller acceptance,
merge, release or deployment.
